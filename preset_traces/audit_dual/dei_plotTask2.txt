You select AM from「已发生的事件概览」, group by time, output <match> then <recall>.

HARD CONSTRAINTS

- AM source: ONLY「已发生的事件概览」. Never invent. Never use AM from USER_INPUT/PREVIOUS_PLOT/背景设定.

- <match> count = <recall> count = required_count. Same AM set.
- Selection by content only. NEVER by time distance, NEVER by AM code order.

==========================================
STEP 3: SELECT (priority order)
==========================================

For each AM, judge link type by CONTENT, not by time:

[REAL LINK] — AM concretely affects current plot:
- 因果链: cause/result/risk/obstacle/next action
- 人物关系: trust/betrayal/promise/grudge/tension
- 共同经历: shared past changes current interaction
- 物品线索: evidence/clue/identity/anomaly
- 矛盾挑战: challenges current claim/stance
- 情感主题: trauma/fear/desire/value conflict
- 地点延续: same place AND place still affects action

[WEAK LINK] — indirect but concrete:
- same character with known attitude/conflict
- same relationship pair with prior tension/debt
- same object/clue/location/organization thread
- same unresolved plot thread

[FALLBACK] — only to fill required_count:
- same character / same pair / same object / same thread / same area
- 类型 must be 补位召回

Pick order: REAL LINK > WEAK LINK > FALLBACK, until count = required_count.

Same keyword/name/place ALONE is NOT REAL LINK. It is WEAK LINK at best.

==========================================
STEP 4: TIME (only for selected AM)
==========================================

current_time_full = USER_INPUT time | PREVIOUS_PLOT last time | max(end_time in 概览)
cur_date  = first YYYY-MM-DD in current_time_full
cur_clock = HH:MM after cur_date

For each selected AM:
  start_date  = first YYYY-MM-DD in 时间跨度
  start_clock = first HH:MM after start_date
  end_date    = second YYYY-MM-DD if any, else = start_date
  end_clock   = last HH:MM in 时间跨度
  if end_date == start_date AND end_clock < start_clock:
    end_date += 1 day
  diff_min  = (cur_date − end_date)*1440 + (cur_clock − end_clock)
  same_date = (cur_date == end_date)
  // diff_min MUST include the date-difference term.
  // date difference ≠ 0  ⇒  same_date=false  ⇒  NEVER now/today.

If missing date/clock OR diff_min<0:
  diff_min=NA, group=unknown, display=记不清时间.

Else pick group (one-step, USE MINUTES DIRECTLY):

  diff_min          | same_date | group     | display
  ------------------+-----------+-----------+----------
  0-120             | true      | now       | Xm
  121-1440          | true      | today     | XhYm
  0-1440            | false     | days      | XdXhYm
  1441-7200         | any       | days      | XdXhYm
  7201-30240        | any       | weeks     | XdXhYm
  30241-86400       | any       | months    | XdXhYm
  86401-259200      | any       | seasons   | XdXhYm
  259201-2628000    | any       | years     | XdXhYm
  2628001+          | any       | old       | XdXhYm

Critical: now/today REQUIRE same_date=true. Any cross-day event starts at days minimum.
Critical boundaries: 120=now,121=today | 1440=today,1441=days | 7200=days,7201=weeks | 30240=weeks,30241=months | 86400=months,86401=seasons | 259200=seasons,259201=years | 2628000=years,2628001=old.

display computation:
  now    → 数字m + "m"                                e.g. 45m
  today  → 数字h + "h" + 数字m + "m"; write m even if 0   e.g. 3h0m / 3h20m
  days~old → full:
    d = diff_min // 1440
    h = (diff_min % 1440) // 60
    m = diff_min % 60
    full = 数字d + "d" + 数字h + "h" + 数字m + "m"      e.g. 5d3h20m
  unknown → 记不清时间
- All d/h/m must be actual computed Arabic numbers; write 0 if 0 (e.g. 5d0h0m / 3h0m).
- Never omit, never copy template literals like XdXhYm / XhYm.

STEP 5: OUTPUT <match>
==========================================

<match>

</match>
