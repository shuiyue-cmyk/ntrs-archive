# R20 规格 —— NTRtrack 独立追踪标签（33 文件预设 + 美化正则）

> 目标：S2 的【黄毛动向追踪】+【对象动向追踪】区块从 thugSpawn 内拆出到独立 `<NTRtrack>` 标签（extractInjectTags，S3 显式 {{NTRtrack}} 引用，不参与 FSD 尾追加）；美化正则加 NTRtrack 解析（黄毛追踪卡 + 对象追踪卡分离渲染），解决对象追踪行被误解析进黄毛人设/备注的问题。

## NTRtrack 输出格式（S2 判定任务输出，在 thugSpawnReason 之后、thugAction 之前）
```
<NTRtrack>
【黄毛动向追踪】（每轮必列，追踪所有已刷新黄毛）
- [黄毛名]（锁定目标 [对象名]）：动向=[在场·[位置] / 离场·[去向] / 尾随·[对象名] / 暗中布局]；线状态=[...]；六型=[...]；型体概要=[...]
【对象动向追踪】（仅离场对象，每对象一行）
- [对象名]：位置=[离场·[去向]]；状态=[独处/社交/外出/在家/工作等]
</NTRtrack>
```
